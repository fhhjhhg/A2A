## 2024-05-24 - [Optimize quantile calculation for large tensors]
**Learning:** When calculating quantiles on large PyTorch tensors (e.g., full MRI volumes > 16 million elements), `torch.quantile` may throw a `RuntimeError` due to size limitations for `float32` tensors. Using `np.percentile` bypasses this, but it returns a `float64` scalar by default. Dividing a `float32` tensor by a `float64` scalar silently promotes the entire tensor to `float64`, doubling memory consumption and causing downstream PyTorch runtime errors (`expected scalar type Float but found Double`).
**Action:** Always cast the result of `np.percentile` to a standard Python `float` (e.g., `float(np.percentile(...))`) before using it in tensor operations to prevent unintended type promotion and OOM errors.
