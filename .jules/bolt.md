## 2024-07-11 - [Optimize Numpy processing in PyTorch Notebook]
**Learning:** In code paths accepting both `np.ndarray` and `torch.Tensor` (common in medical imaging tools like `meddlr`/SKM-TEA), avoiding round-trip tensor conversion for mathematical operations (like calculating percentiles and clipping) yields significant performance gains. Here, using `np.percentile` instead of converting to tensor and back to use `torch.quantile` yielded ~9x speedup for NumPy arrays and bypassed `torch.quantile`'s hard size limits for float32 tensors (>16M elements). Also, remember that `np.percentile` takes a range of [0, 100], whereas `torch.quantile` uses [0, 1].
**Action:** Always look for opportunities to use native library functions (NumPy native, PyTorch native) conditionally based on input type rather than forcing all inputs through a single conversion funnel, especially for large multidimensional arrays.
