## 2024-05-24 - [Avoid RuntimeError with torch.quantile on large float32 tensors]
**Learning:** `torch.quantile` can throw a `RuntimeError` on large data structures (like full MRI volumes > 16M elements) due to size limitations for `float32` tensors. Also, `np.percentile` returns a `numpy.float64` scalar by default, which silently promotes the entire array to `float64` upon division, doubling memory consumption and causing downstream PyTorch runtime errors (`expected scalar type Float but found Double`).
**Action:** Use `np.percentile` on NumPy arrays instead to handle these larger data structures efficiently. Always explicitly cast the result to a standard Python `float` (e.g., `float(np.percentile(...))`) to prevent float64 memory bloat/promotion. Note that `np.percentile` expects a range of [0, 100] while `torch.quantile` uses [0.0, 1.0].
