## 2024-05-24 - [Parallelize I/O-bound shell commands in Jupyter Notebooks]
**Learning:** Using IPython `!` magic for I/O-bound shell commands (like `wget` and `tar`) in loops executes sequentially and is not thread-safe. Additionally, when using `subprocess.Popen`, routing `stderr` or `stdout` to `subprocess.PIPE` without reading it can deadlock due to OS pipe buffers filling up. Suppressing `stderr` to `subprocess.DEVNULL` masks progress, requiring alternative UX like `tqdm` over `concurrent.futures.as_completed`.
**Action:** Use `ThreadPoolExecutor` with `subprocess` for parallel execution. Ensure thread exceptions are propagated by calling `.result()` on futures yielded by `as_completed()`, or by explicitly consuming the generator returned by `executor.map()`. To avoid deadlocks in piped commands (e.g. `wget | tar`), close the upstream stdout after creating the downstream process, use `.wait()` on the upstream, and redirect unneeded streams to `subprocess.DEVNULL`.
