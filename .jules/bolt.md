## 2024-11-20 - Throttling Stream Rendering in Jupyter Notebooks
**Learning:** Continuous DOM manipulation in Jupyter via `clear_output(wait=True)` and `display()` on every generated token causes severe frontend UI freezing and browser lockup during long text streams. It heavily blocks the main thread.
**Action:** When implementing text streaming in Jupyter Notebooks (especially using `ai.generate_text(stream=True)`), accumulate the streamed chunks in a variable and throttle the `clear_output()`/`display()` calls using `time.time()` (e.g., updating every 0.1s). Always remember to include a final flush `clear_output()` and `display()` outside the loop to render the last accumulated chunks. When using time deltas, add `# noqa: PLR2004` to bypass the magic number linting rule.
