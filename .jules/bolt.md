## 2024-05-15 - [Optimize chunking loop with tqdm and tensor view]
**Learning:** In PyTorch code, element-wise operations like `unsqueeze` should be hoisted outside chunking loops to operate on the entire tensor at once. This avoids repeated overhead from allocating new tensor views or graph nodes per chunk. Furthermore, when using `tqdm` with a conditional toggle (e.g. `disable=not pbar`), conditionally wrapping the iterable (e.g. `if pbar: chunks = tqdm(chunks)`) is better than using `tqdm(..., disable=True)` since the latter still introduces measurable overhead inside performance-critical loops.
**Action:** When parallelizing or chunking, apply full-tensor transformations (like `unsqueeze`) before splitting. For conditional `tqdm`, conditionally wrap the iterator instead of using the `disable` flag on `tqdm` inside the loop.
