## 2024-05-20 - Prevent implicit float64 promotion in NumPy scalar division
**Learning:** `np.percentile` returns a `numpy.float64` scalar by default. Dividing a `float32` NumPy array (like a large MRI volume) by this scalar silently promotes the entire array to `float64`, doubling memory consumption. However, for PyTorch tensors, casting scalar metrics like `torch.quantile` to a standard Python `float` detaches them from the computation graph and forces a synchronous Device-to-Host (D2H) memory transfer if the tensor is on a GPU, causing severe performance regressions.
**Action:** Always explicitly cast the result of `np.percentile` to a standard Python `float` (e.g., `float(np.percentile(...))`) before using it in operations with `float32` arrays. Never cast PyTorch scalar tensors to standard Python floats.
