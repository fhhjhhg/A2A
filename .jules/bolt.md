## 2024-05-24 - [Preserving Jupyter Notebook formatting during programmatic edits]
 **Learning:** Using `json.dump(..., indent=2)` on `.ipynb` files can sometimes introduce significant diff noise if the original file was formatted with `indent=1` or inconsistent spacing. Furthermore, regex replacements to remove execution outputs can break JSON syntax if not carefully targeted or if there are nested structures (like replacing `"outputs": \[.*?\]` with `re.DOTALL`).
 **Action:** For performance optimizations in `.ipynb` files where clean PR diffs are essential, prefer precise string replacements (`content.replace(old, new)`) or safe, non-greedy regex over JSON loading/dumping when the indentation style is unknown or irregular. Always verify JSON validity (`python -m json.tool file.ipynb > /dev/null`) after raw text edits.
