## 2024-11-20 - Optimizing text streaming in Jupyter Notebooks
**Learning:** In text streaming loops in Jupyter Notebooks (like those simulating LLM output using `accumulated_content += new_chunk` followed by `clear_output(wait=True)` and `display(Markdown(accumulated_content))`), appending chunks to a string and repeatedly clearing/rendering the full accumulated content scales quadratically (O(N^2)). The bottleneck is updating the display by rendering the entire growing markdown block on every single iteration, which can cause significant jank and overhead for long responses.
**Action:** When optimizing such loops, replacing `+=` with `list.append` and `"".join()` inside the loop still copies the string and doesn't remove the O(N^2) complexity. The true fix requires either throttling the display updates (e.g. using `time.time()` to only `display()` and `clear_output()` a few times a second), or using an `IPython.display.display(..., display_id=True)` object and calling `.update()` with the full text, though even that requires re-rendering the full markdown. Alternatively, you can collect strings in a list and join them.
