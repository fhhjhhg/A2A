## 2024-11-01 - Avoid Casting NumPy Arrays to PyTorch Tensors for Quantile Computation
**Learning:** In utility functions (e.g., `get_scaled_image`) that handle both NumPy arrays and PyTorch tensors, checking `is_numpy` and blindly converting NumPy arrays to PyTorch tensors (via `torch.as_tensor`) just to use PyTorch's `torch.quantile` creates unnecessary tensor instantiation overhead and potential blocking data transfers. If a user passes a NumPy array, it's better to keep it as a NumPy array and use `np.percentile`.
**Action:** When conditionally branching logic for NumPy arrays vs PyTorch tensors to compute quantiles, use the respective library's native methods: `np.percentile(x, percentile * 100)` for NumPy arrays and `torch.quantile(x, percentile)` for PyTorch tensors. Also, ensure the return result of `np.percentile` is cast to standard python `float` to avoid implicit arrays memory explosion during division operations.
