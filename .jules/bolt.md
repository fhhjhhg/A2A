## 2024-06-25 - Parallelizing I/O-bound Jupyter Cell Commands
**Learning:** In the `SKM_TEA_Dataset_Tutorial.ipynb` notebook, the dataset download setup initially utilized multiple sequential `!wget` and `!tar` calls, causing unnecessary delays (downtime). Because these commands are heavily I/O bound, standard shell loops or sequential magic commands (`!`) fail to exploit concurrent network and disk availability.
**Action:** Replace shell loops and sequential magic `!` commands with native Python code utilizing `ThreadPoolExecutor` and `subprocess.run` to execute downloading (`wget`) and extraction (`tar`) concurrently. By submitting tasks to the executor and using `concurrent.futures.as_completed()`, total time decreases significantly, optimizing the setup performance overhead.
