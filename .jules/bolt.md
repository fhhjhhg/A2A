## 2024-05-24 - Optimize NumPy array percentile calculation
**Learning:** In PyTorch/NumPy mixed pipelines, unnecessarily coercing a `float32` NumPy array to a PyTorch tensor on a device just to compute a quantile can cause severe regressions due to Device-to-Host (D2H) memory transfers or unnecessary tensor instantiation. Using `torch.quantile` on CPU NumPy arrays by first doing `torch.as_tensor()` adds conversion overhead.
**Action:** When calculating quantiles on `ndarray`s, use the native `np.percentile` directly (with percentile * 100). Do not indiscriminately convert NumPy arrays to PyTorch tensors for standard scalar metrics. Also, remember to explicitly cast the result of `np.percentile` to `float` as it returns a `numpy.float64`, which would otherwise silently promote subsequent PyTorch computations to `float64`, doubling memory consumption.
